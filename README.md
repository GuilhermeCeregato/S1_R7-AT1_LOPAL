## 📋 Lista de Exercícios (JavaScript)

### 1. Validação de Número Positivo
O programa solicita um número positivo e repete a pergunta enquanto o usuário digitar valores negativos.
* **Técnica:** Laço `while` para validação.

### 2. Média de Notas
O usuário insere notas de 0 a 10 indefinidamente. O programa encerra ao receber um número negativo e calcula a média das notas anteriores.
* **Técnica:** Acumuladores e condição de parada.

### 3. Totalizador de Compras
Soma valores de produtos inseridos pelo usuário. A execução é finalizada quando o valor `0` é digitado, exibindo o total da compra.
* **Técnica:** Estrutura `do...while`.

### 4. Validação de Nome e Sobrenome
Solicita nome e sobrenome separadamente, impedindo que os campos fiquem vazios ou contenham apenas espaços.
* **Técnica:** Tratamento de strings com `.trim()`.

### 5. Simulação de Saque Bancário
Gerencia saques de uma conta com saldo inicial simulado. O programa impede saques maiores que o saldo disponível e encerra quando o saldo chega a zero.
* **Técnica:** Controle de fluxo e decremento de variáveis.
